# eVisa Device Browser — Side Panel v1.1

1. Extract this folder.
2. Open `edge://extensions` or `chrome://extensions`.
3. Enable Developer mode.
4. Load unpacked and select this folder.
5. Enable site access for Railway and the Nigeria eVisa portal if the browser asks.
6. Click the eVisa Device Browser toolbar icon. The assistant opens as a persistent side panel.
7. In Connection settings, enter the Railway username/password and keep **Enable device worker** checked.
8. Select an applicant and press **Start Automation**.

The current browser tab becomes the eVisa portal. The assistant remains visible in the side panel, so no second tab is required.
