# Web Perfect v9 — Queue Search, Single Select, Manual Submitted, ASKY, Required-field Highlighting, Upload Logs

- Added queue search by applicant ID, name, passport, nationality, visa and status.
- Added Status and Visa filters plus Clear.
- Queue selection is now one applicant at a time (radio selection); multi-select/select-all is removed.
- Added **Mark as Submitted** button. It updates status/timestamp, turns the row green, and moves it into the submitted group at the bottom (most recent submitted first).
- Added **ASKY Airlines** to Travel Carrier and `KP` Quick Fill flight-prefix detection.
- Required applicant-form fields display red until filled; optional Other Names, Postal Code, Notes and Status remain neutral.
- Folder document uploads now write all uploaded filenames to Activity.
- Automation activity now displays event messages and Page 5 uploaded filenames when supplied by local automation or the device extension.
- All v8 and earlier functionality is retained.
