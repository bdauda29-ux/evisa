# Web Perfect v3 — Applicant Setup Wizard

Applicant setup now flows automatically in this order:

1. Fill / Quick Fill Applicant Form.
2. Click Save.
3. Document Assignment opens automatically for that same applicant.
4. Assign the documents and click Save Assignment.
5. If the visa-specific Passport Photo / Passport Photograph position contains an image, the Crop Passport Photograph editor opens automatically.
6. Crop and save the passport photograph.

The Application ID, 11-line Quick Fill, airline additions, hotel/host source file, CSV and SQLite features from v2 are retained.
