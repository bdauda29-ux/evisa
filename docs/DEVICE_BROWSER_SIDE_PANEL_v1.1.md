# Device Browser Side Panel v1.1

The Windows Chrome/Edge extension now uses the Side Panel API. The extension action opens a persistent assistant panel while the main browser area is reserved for the Nigeria eVisa portal.

The panel can load applicants from Railway, choose a start page, start/cancel a device job, refresh applicants, show the portal in the current tab, and configure Railway credentials. Starting a job reuses the current normal web tab when no portal tab exists instead of opening a second tab.
