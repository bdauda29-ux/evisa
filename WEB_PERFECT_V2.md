# Web Perfect v2

Changes:
- Travel Carrier includes Kenya Airways, Royal Air Maroc, and South African Airways.
- Flight prefixes: KQ = Kenya Airways, AT = Royal Air Maroc, SA = South African Airways.
- The + button beside Contact Name is now Add Hotel / Host Address. Records save in SQLite and therefore travel with SQLite export/import.
- Permanent source-seeded hotels can be added to backend/config/hotels.json.
- Quick Fill has 11 lines; line 11 is Nationality.
- Nationality recognizes a unique first 3+ letters and completes the country.
- For new applicants, line 2 Surname automatically becomes Application ID if Application ID is blank; Application ID remains editable.
