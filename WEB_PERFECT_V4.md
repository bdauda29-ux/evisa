# Web Perfect v4 — Applicant Defaults

Added applicant-form defaults:
- Marital Status defaults to **Single** when the applicant has no saved marital status.
- Arrival Channel defaults to **Air** when the applicant has no saved arrival channel.
- Both remain editable and saved normally.
- Existing saved applicant values are preserved and are not overwritten.

All Web Perfect v3 features are retained.
