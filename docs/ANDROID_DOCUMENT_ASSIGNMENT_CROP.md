# Android document assignment + photograph crop

- Folder/cloud files are shown under **Available files**.
- When a file is assigned to a document position it disappears from the available list immediately.
- The same file is disabled in every other document-position dropdown to prevent duplicate assignment.
- Clearing an assignment makes that file available again.
- Visa document positions continue to use the Windows visa-specific labels.
- Positions whose label contains `Photo` or `Photograph` show a **Crop** button after a file is assigned.
- The Android crop editor supports drag/reposition, zoom, rotate left/right, reset, and saves an exact 600 x 600 JPEG copy.
- The cropped copy replaces the photograph assignment automatically and is stored in the app's persistent files directory.
